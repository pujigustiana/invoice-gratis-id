# Invoice Gratis ID — Buat Invoice Online Gratis, Cetak PDF

Buat invoice Bahasa Indonesia langsung di browser. **Gratis, tanpa daftar, tanpa biaya, tanpa server.** Cocok untuk UMKM, freelancer, toko online, dan usaha kecil yang butuh invoice rapi dalam hitungan menit.

**Coba langsung:** buka file `index.html` di browser, atau kunjungi repo ini: https://github.com/pujigustiana/invoice-gratis-id

## Kenapa pakai ini?
- **Gratis selamanya untuk fitur dasar** — tidak ada paywall, tidak ada akun.
- **Privasi:** semua perhitungan terjadi di browsermu. Data invoice tidak dikirim ke server mana pun.
- **Cepat:** total otomatis, PPN 11% opsional, terbilang rupiah otomatis.
- **Praktis:** cetak atau simpan sebagai PDF dengan satu klik.

## Cara pakai
1. Buka `index.html` di browser (atau unduh repo ini).
2. Isi nama usaha, pelanggan, dan baris item — total dan terbilang terhitung otomatis.
3. Centang PPN 11% bila perlu.
4. Klik **Cetak / Simpan PDF** untuk menyimpan sebagai PDF.
5. Klik **Simpan di browser ini** untuk menyimpan draf di perangkatmu (localStorage, tidak dikirim ke mana pun).

## Fitur
- 100% berjalan offline, satu file HTML, tanpa dependency.
- Total otomatis, PPN 11% opsional, terbilang rupiah otomatis.
- Tambah/hapus baris item, simpan draf di browser.

## Pertanyaan umum (FAQ)
**Apakah benar-benar gratis?** Ya. Fitur dasar gratis, tanpa akun dan tanpa batas jumlah invoice.
**Apakah dataku aman?** Ya. Aplikasi berjalan sepenuhnya di browsermu (localStorage). Tidak ada server, tidak ada data yang dikirim keluar.
**Bagaimana cara menyimpan sebagai PDF?** Klik "Cetak / Simpan PDF", lalu pilih "Save as PDF" di dialog cetak browsermu.
**Apakah bisa dipakai untuk UMKM dan freelancer?** Ya — dibuat untuk usaha kecil, freelancer, dan toko online di Indonesia.
**Apakah ada PPN?** Opsional. Centang "Tambah PPN 11%" bila transaksimu kena PPN.
